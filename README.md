# Sistema de Registro de Productos – CRUD en Java

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación de escritorio en Java que permite gestionar el registro de productos mediante las operaciones CRUD (*Create, Read, Update, Delete*), es decir: crear, consultar, actualizar y eliminar registros.

La aplicación cuenta con una interfaz gráfica desarrollada en Apache NetBeans y está conectada a una base de datos MySQL, donde se almacena la información de los productos para facilitar su administración.

Este ejercicio hace parte del proceso de aprendizaje y práctica de programación en Java, diseño de interfaces gráficas y conexión con bases de datos.

## Tecnologías y herramientas utilizadas

- **Java:** lenguaje de programación utilizado para desarrollar la aplicación.
- **JDK (Java Development Kit):** conjunto de herramientas necesario para compilar y ejecutar programas Java.
- **Apache NetBeans:** entorno de desarrollo integrado (IDE) utilizado para escribir el código y diseñar la interfaz gráfica.
- **MySQL:** sistema gestor de bases de datos utilizado para almacenar la información.
- **JDBC:** tecnología utilizada para establecer la conexión entre Java y MySQL.

## Funcionalidades principales

El sistema permite realizar las siguientes operaciones:

- **Crear:** registrar nuevos productos en la base de datos.
- **Leer:** consultar y visualizar los productos registrados.
- **Actualizar:** modificar la información de los productos existentes.
- **Eliminar:** borrar productos de la base de datos.

## Estructura general del funcionamiento

La aplicación funciona mediante la interacción de tres elementos principales:

1. **Interfaz gráfica:** permite al usuario ingresar y administrar la información de los productos.
2. **Lógica de programación en Java:** procesa las acciones realizadas desde el formulario.
3. **Base de datos MySQL:** almacena y proporciona la información solicitada por la aplicación.

## Objetivo del proyecto

Aplicar los conocimientos básicos de programación en Java y gestión de bases de datos mediante el desarrollo de una aplicación funcional que permita administrar productos y comprender el funcionamiento de las operaciones CRUD.
